Once Human Field Guide

Upload index.html, style.css, app.js en items.json naar de hoofdmap van een openbare GitHub-repository. Activeer Settings → Pages → Deploy from a branch → main → /(root).

De startcatalogus bevat 8 items en is niet compleet. Controleer gegevens in-game voor jouw scenario. Illustraties zijn generieke symbolen, geen game-assets. Favorieten en geïmporteerde gegevens blijven lokaal in de browser. Vervang items.json om wijzigingen te publiceren.

Open via een webserver; direct openen als lokaal bestand ondersteunt het laden van JSON niet in alle browsers. Voor lokale preview: python -m http.server 8000
