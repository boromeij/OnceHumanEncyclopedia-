GRATIS HOSTING

Publiceer met GitHub Pages

  1. Maak een gratis GitHub-account en een openbare repository once-human.
  2. Download hieronder de website en pak het ZIP-bestand uit.
  3. Upload de inhoud via Add file → Upload files. Zet index.html direct in de hoofdmap.
  4. Open Settings → Pages. Kies Deploy from a branch → main → /(root) → Save.
  5. Je website verschijnt op jouwnaam.github.io/once-human/.
