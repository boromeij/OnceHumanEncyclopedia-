JOUW GITHUB PAGES-SITE

De encyclopedie bijwerken

  1. Voeg items toe via Beheer of pas _data/items.json aan in GitHub.
  2. Gebruik na lokale wijzigingen Catalogus downloaden (.json) en vervang daarmee _data/items.json in de repository.
  3. Sla de wijziging op met Commit changes. Jekyll publiceert de bijgewerkte gegevens via GitHub Pages.
  4. Als je eerder een lokale catalogus hebt geïmporteerd, klik op Beheer → Lokale catalogus herstellen om weer de gepubliceerde gegevens te gebruiken.
